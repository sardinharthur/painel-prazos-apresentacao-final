# Como acessar o painel no computador do professor

1. Instale Python 3.11 ou mais recente.
2. Baixe o ZIP do repositório e extraia a pasta inteira.
3. Abra **Abrir_Painel.bat**.
4. Na tela de login, digite **login@fesppr** e **@integrador2026**.
5. Consulte os painéis com os 264 registros reais da coleta de 18/11/2026.

O professor pode usar as buscas, os filtros, as abas, a acessibilidade e a
navegação dos painéis dos robôs. A conta tem acesso de leitura. A execução dos
robôs será demonstrada pelo responsável pelo projeto.

O servidor da banca funciona com a biblioteca padrão do Python e com os dados
incluídos no projeto. O README detalha os arquivos usados e o funcionamento.

No macOS, Windows ou Linux, execute `python3 servidor_avaliacao.py` na pasta extraída.

Para abrir a instalação institucional configurada com Neon e credenciais dos
portais, use **Abrir_Painel_Neon.bat**.
